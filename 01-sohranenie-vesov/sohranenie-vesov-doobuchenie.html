Что внутри · model.state_dict()

Веса — это словарь: имя слоя → тензор

Настоящий вывод для модели занятия

for name, w in model.state_dict().items():
    print(f'{name:10s} {tuple(w.shape)}')
0.weight (16, 3, 3, 3) 0.bias (16,) 3.weight (32, 16, 3, 3) 3.bias (32,) 6.weight (64, 32, 3, 3) 6.bias (64,) 11.weight (5, 9216) 11.bias (5,)

Как читать

  • 0.weight — слой номер 0 в Sequential, это первая свёртка: 16 ядер по 3 канала 3×3
  • Номеров 1, 2, 4, 5… нет: у ReLU, MaxPool2d, Flatten, Dropout весов нет
  • 11.weight (5, 9216) — последний Linear: 5 классов × 9216 входов
  • Все числа вместе — 69 669, файл весит около 275 КБ
В файл попадают только числа. Архитектуры там нет — модель для загрузки создаём тем же кодом.

Проверочная выборка · сначала перемешать

Экзамен — на задачах, которых сеть не видела

Схема: одна клетка ≈ 43 фото. Картинки лежат по порядку классов.
Проверочная выборкаЧасть данных, на которой сеть не учится. По ней видно, научилась сеть или зазубрила.
  • x_train, y_train — учим
  • x_val, y_val — проверяем после каждой эпохи
  • 4317 фото → 3670 на обучение и 647 на проверку (15 %)
  • По ней выбираем лучшую эпоху и решаем, помогло ли дообучение
Номера сначала перемешиваем (torch.randperm), потом режем.
Зачем сохранять каждую эпоху

Последняя эпоха — не обязательно лучшая

ошибка на обучающейошибка на проверочнойлучшая эпоха

Настоящий запуск · 20 эпох, lr = 0.001

  • Ошибка на обучающей падает почти всё время: сеть всё лучше знает свои картинки
  • Ошибка на проверочной скачет: на 18-й эпохе 0.857 против 0.714 на 17-й
  • Лучшая — 17-я: val_loss 0.7137, точность 0.726
  • Если учить дальше, разрыв растёт — это переобучение
Сохраняем веса после каждой эпохи, а потом берём файл с наименьшей ошибкой на проверке.

callback — «позвони мне после эпохи»

# внутри готовой fit, в конце каждой эпохи:
if callback:
    callback(model, epoch, val_loss)

Свою функцию checkpoint вы передадите в fit, и она будет сохранять веса сама.

Как достать ошибку из имени

p = 'flowers-2026-10-04_22-12_017-0.713699.pt'
p[:-3].rsplit('-', 1)
['flowers-2026-10-04_22-12_017', '0.713699']
  • p[:-3] — отрезали .pt
  • rsplit('-', 1) — один разрез по последнему дефису: дефисы в дате не мешают
  • Дальше float(...) и минимум по всем файлам
Лучший файл — с наименьшим val_loss, а не самый свежий.
Дообучение · сначала интуиция

Большими шагами яму не найти — нужны маленькие

схематично
ДообучениеПродолжаем учить уже обученную сеть с сохранённых весов, а не с нуля.
  • Большой lr быстро приводит в нужную долину, но потом сеть прыгает со склона на склон
  • Загрузили лучшие веса, уменьшили lr в 10 раз — и спускаемся аккуратно
  • Циклов может быть несколько: 0.001 → 0.0001 → 0.00001
Дообучение = лучшие веса + lr в 10 раз меньше + тот же журнал эпох.

Дообучение · когда пришли новые данные

Добавили фото — учим дальше, а не с нуля

Порядок действий

1создать модель тем же кодом и загрузить веса
2добавить новые фото к старым: torch.cat
3учить несколько эпох с маленьким lr
4сравнить на той же проверочной выборке

Учить только на новых фото опасно: сеть подстроится под них и забудет старые.

А если добавили новый класс?

Выход сети станет на один нейрон больше — последний слой не совпадёт по форме (настоящая ошибка):

size mismatch for 11.weight: copying a param with shape torch.Size([5, 9216]) from checkpoint, the shape in current model is torch.Size([6, 9216]).
Свёрточные слои можно взять из старых весов, а последний слой учится заново. Это уже перенос обучения — к нему вернёмся на предобученных сетях.
